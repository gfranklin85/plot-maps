## Merch-ready quick references

### For a T-shirt / hoodie order
- **Cream tee (Comfort Colors "Ivory" or "Sandstone")** + coral `#C8553D` chest print = signature look
- **Navy tee (Comfort Colors "True Navy")** + cream `#F4EAD5` chest print = inverse, formal
- **Heather grey tee** + coral `#C8553D` print = casual, friendly

### For embroidery (hats, polos)
- Madeira thread: **Coral = #1747** (closest match to `#C8553D`)
- Madeira thread: **Cream = #1082** (closest match to `#F4EAD5`)
- Madeira thread: **Navy = #1843** (closest match to `#1D3557`)
- Madeira thread: **Safety Orange = #1278** (closest match to `#F26B1F`)
- Madeira numbers are approximate — confirm with your embroiderer's swatch book.

### For stickers / vinyl decals
- **Die-cut stickers**: coral `#C8553D` logo on white background, OR cream `#F4EAD5` cutout on transparent vinyl
- **Vehicle vinyl**: 3M cast vinyl #7725-23 ("Bright Red") is the closest stock match to coral; for exact match, request **Pantone 7417 C** custom mix

### For business cards / letterhead
- **Card stock**: French Paper "Construction Insulation Pink" (close to coral) or "Speckletone Madero Beach" (close to cream parchment)
- **Print spec**: Pantone 7417 C (coral) + Pantone 7527 C (cream) + Pantone 539 C (blueprint navy)
- **Tip for premium feel**: use letterpress or foil stamping in coral on cream

### For yard signs / corrugated signage
- **Coroplast white** + cream `#F4EAD5` flood + coral `#C8553D` text = clean Plot-branded sign
- **Aluminum sign** + coral `#C8553D` background + cream text = real-estate-industry-standard format in Plot colors

### For social media graphics
- **Instagram square**: cream background + coral text + blueprint navy supporting text
- **LinkedIn header**: cream → blueprint-navy gradient with coral accent
- **Avatar / profile pic**: solid coral background with cream "P" mark

## Usage rules

### DO
- **Always start with cream as the surface.** The brand lives on parchment.
- **Use coral for one primary action per screen / surface.** Don't dilute it with multiple corals.
- **Reserve safety orange for "marking" moments.** Prospect pins, stake actions, claim CTAs — that's it. Using it elsewhere weakens its meaning.
- **Use blueprint navy for technical / data content.** It signals "this is information you can trust and measure."
- **Use the status palette consistently.** A hot lead is always coral. A pending listing is always peach. An active listing is always lemon. Build the visual grammar.

### DON'T
- **Don't use pure white as a primary background.** Always cream. Pure white reads as generic SaaS.
- **Don't use pure black for text.** Always blueprint ink `#1A1F2E`. Pure black is harsh against cream.
- **Don't put coral and safety orange next to each other in big areas.** They fight. Use one for chrome, one for action.
- **Don't substitute Tailwind defaults** (`text-slate-600`, `bg-blue-500`, etc.). Use only the tokens in this document.
- **Don't introduce a new color without updating this document.** Discipline keeps the brand recognizable.
