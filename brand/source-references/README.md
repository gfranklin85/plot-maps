# Source References — Mood Board

> **Important**: Images in this folder are reference / mood board material **only**. Do not ship as production assets.

## What goes here

- AI-generated mockups that establish visual direction
- Reference photography from books, museums, websites
- Screenshots of products in the same visual neighborhood
- Scans of physical materials (vintage maps, surveyor's tools, plat books)
- Inspiration from games, films, editorial design

## Why not ship them

- **AI-generated images have IP / licensing ambiguity** — courts are still figuring out who owns them
- **AI-fabricated text** ("Office of Field Quality," "Plot Crew Approved") is hallucinated; it's not real brand language we own
- **Quality plateaus** — AI images look great at small sizes but break down at large display sizes or close inspection
- **Brand discipline** — if we ship AI images as "Plot's brand," we don't actually own our visual identity. We're renting it from a model

## How to use them

1. Look at them when designing
2. Match the *vocabulary* (materials, light, composition) with hand-crafted assets
3. Use them as the visual target when reviewing what we've made — "does our compass feel like the compass in mockup-1?"
4. Eventually, every reference image should have a hand-crafted equivalent in `/public/`

## File naming convention

`{type}-{subject}-{description}.{ext}`

Examples:
- `mockup-survey-table-dashboard.png` — full mockup of the dashboard concept
- `mockup-plat-book-activity.png` — full mockup of the activity view
- `ref-brass-compass-antique.jpg` — single-object reference
- `ref-plat-book-1923-county.jpg` — period-correct historical reference
- `scan-uscgs-topo-fresno-1952.png` — actual scanned vintage map

## Visual cues to extract from these mockups

When crafting real assets, match these recurring elements:
- **Material palette**: brass (warm gold with patina), leather (dark cordovan + cream stitching), parchment (cream `#F4EAD5` aged), walnut wood (rich brown with grain), ink (blueprint navy `#1D3557` + oxide red `#C8553D`)
- **Light**: warm gold from upper-left/right, casting soft shadows to the lower-right (matches our canonical light direction)
- **Stamps**: circular ink stamps with concentric ring borders, often slightly off-axis (hand-applied feel)
- **Typography on objects**: condensed slab serifs for headlines, light tracking, color-coded by tool
- **Paper edges**: deckled, slightly torn, lifted at corners (not crisp rectangles)
- **Object placement**: casual, slightly rotated, never grid-aligned — "left there during work"
